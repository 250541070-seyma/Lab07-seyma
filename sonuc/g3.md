# Gorev 3 - Yuzlestirme: SQL vs Dokuman

**Soru:** En cok kayit alan dersin kayit sayisi kac?

## 1. PostgreSQL (Iliskisel Model) Sorgusu ve Sonucu

    SELECT d.ders_id, d.ad, COUNT(*) AS adet
    FROM dersler d
    JOIN kayitlar k ON d.ders_id = k.ders_id
    GROUP BY d.ders_id, d.ad
    ORDER BY adet DESC
    LIMIT 1;

**Sonuc:** ders_id = 25 (Sabah Yogasi - Ileri) olan ders, **19** kayit ile en cok kayit alan derstir.

## 2. MongoDB (Dokuman Modeli) Aggregate Boru Hatti ve Sonucu

    db.kayitlar.aggregate([
      { $group: { _id: "$ders_id", adet: { $sum: 1 } } },
      { $sort: { adet: -1 } },
      { $limit: 5 }
    ])

**Sonuc:** _id: 25 olan ders **19** kayit almistir (her iki dunyada da sonuc birebir aynidir).

## 3. Degerlendirme

Iliskisel semaya aliskin olundugu icin standart JOIN + GROUP BY soz dizimini yazmak ilk bakista daha dogal gelse de, MongoDB'de kayitlar koleksiyonunda ders_id zaten bulundugu icin JOIN yapmadan dogrudan group asamasiyla sonuca ulasmak cok daha kisa ve pratiktir. Ders karti ekraninda (ders, egitmen ve salon bilgilerinin birlikte gosterilmesi) dokuman modeli acik ara avantajlidir; cunku egitmen ve salon alt dokuman olarak gomulu oldugundan tek bir okuma (single read) ile tum kart bilgisi getirilebilir. Buna karsilik bir egitmenin adi veya bilgisi degistiginde, verinin tekrarlandigi (denormalize edildigi) MongoDB modelinde o egitmenin verdigi tum ders dokumanlarinin tek tek guncellenmesi gerekeceginden guncelleme maliyeti ve tutarsizlik riski yuksek olur. FiratFit sisteminde uyelik odemeleri, bakiye hareketleri ve siki butunluk (foreign key) gerektiren kayit islemleri icin PostgreSQL'i; ders katalogu, egitmen profilleri ve esnek alanlara sahip egzersiz programlari icin ise MongoDB'yi secerdim.
